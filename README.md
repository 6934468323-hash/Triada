# Tríada Reader

แอปฝึกอ่านภาษาฝรั่งเศส สเปน และดัตช์ (ภาษาของ UI คือไทย) ใช้งานออฟไลน์ได้ทั้งหมด ยกเว้นฟีเจอร์ที่ระบุว่าเป็นแบบออนไลน์

## ฟีเจอร์

เนื้อหาในแอปแต่ละภาษามีโพสต์ 14–15 โพสต์ บทความพร้อมแบบทดสอบ 7 บท และนิยาย 4 เรื่อง

| ส่วน | สิ่งที่ทำได้ |
|---|---|
| **ฟีด** (3.1) | อ่านโพสต์พร้อมคอมเมนต์แบบโซเชียลมีเดีย กรองตามหมวด (อาหาร ท่องเที่ยว ชีวิตประจำวัน เทคโนโลยี กีฬา บันเทิง การงาน ธรรมชาติ) และระดับ CEFR เลื่อนอ่านได้ไม่สิ้นสุด เมื่ออ่านครบจะสุ่มลำดับใหม่แล้ววนอีกรอบ |
| **ความรู้** (3.2) | บทความด้านวิทยาศาสตร์ สุขภาพ ประวัติศาสตร์ สังคม เศรษฐกิจ เทคโนโลยี และข่าว กรองตามระดับ CEFR อ่านจบแล้วมีคำถามปรนัย 5 ข้อแบบข้อสอบ (ใจความสำคัญ ข้อใดไม่สอดคล้อง การอนุมาน ศัพท์ในบริบท จุดประสงค์ และน้ำเสียงของผู้เขียน) พร้อมเฉลยภาษาไทย |
| **อ่านข่าว** | มีสี่แท็บ คือ ข่าวล่าสุด (Wikinews) · กำลังเป็นกระแส (บทความยอดนิยมเมื่อวานจาก Wikipedia) · บันทึกไว้ · วางบทความเอง (คัดลอกข่าวจากเว็บใดก็ได้มาวาง) ทุกบทความที่เปิดจะได้ระดับ CEFR โดยประมาณ คำยาก และแบบทดสอบอัตโนมัติ 5 ข้อ (เติมคำ ความหมายในบริบท และประโยคใดไม่อยู่ในบทความ) แปลทุกประโยคออนไลน์ได้ แล้วเก็บไว้อ่านออฟไลน์ได้สูงสุด 40 เรื่อง |
| **นิยาย** (3.3) | เรื่องสั้นแนวสืบสวน โรแมนติก สยองขวัญ ตลก และแฟนตาซี มีแถบบอกความคืบหน้า และจำได้ว่าอ่านถึงไหนแล้ว |
| ทุกโหมด | แตะคำเพื่อดูความหมาย (ไทยและอังกฤษ) รูปพื้นฐานของคำ ชนิดคำ และระดับ CEFR ตรวจจับสำนวนหลายคำได้ แปลทั้งประโยคหรือทุกประโยคเป็นไทยหรืออังกฤษ ฟังเสียงอ่านทั้งเรื่อง (ไฮไลต์ประโยคที่กำลังอ่าน) หรือฟังทีละคำ/ประโยค |
| **การ์ด** | เมื่ออ่านจบ ระบบบันทึกคำยากให้อัตโนมัติ (ค่าเริ่มต้นคือคำที่ยากกว่าระดับของบทความ 1 ขั้น และอย่างน้อย B1) ทบทวนแบบ Spaced Repetition 4 ระดับ (ลืม/ยาก/จำได้/ง่ายมาก) การ์ดแต่ละใบมีประโยคตัวอย่างจากเรื่องที่อ่าน |
| **พจนานุกรม** | ค้นหาคำศัพท์ได้ทั้งจากคำต่างประเทศ (ไม่ต้องพิมพ์เครื่องหมายกำกับเสียง) หรือค้นย้อนกลับจากคำไทย/อังกฤษ แสดงประโยคตัวอย่างจากคลังบทความ เมื่อออนไลน์จะค้นต่อใน Wiktionary และ MyMemory สำหรับคำที่ไม่มีในเครื่อง |
| **ตั้งค่า** | ภาษาของหน้าแอป (ไทย/English แยกจากภาษาคำแปล) ธีม (ตามระบบ/สว่าง/มืด/กระดาษ) สีหลัก ขนาดตัวอักษร ระยะบรรทัด ฟอนต์ ภาษาคำแปล ขีดเส้นใต้คำยาก เกณฑ์คำยาก ด้านหน้าการ์ด จำนวนการ์ดต่อรอบ ความเร็วและเสียงอ่าน ส่งออก/นำเข้าข้อมูล |

## วิธีใช้งาน

- **ไฟล์เดียว:** เปิดไฟล์ `docs/triada-offline.html` ในเบราว์เซอร์ได้เลย ไม่ต้องใช้อินเทอร์เน็ต
- **ติดตั้งเป็นแอป (PWA):** เปิด https://6934468323-hash.github.io/Triada/ (GitHub Pages ที่เปิดไว้จากโฟลเดอร์ `docs/`) หนึ่งครั้ง แล้วกด "เพิ่มลงหน้าจอหลัก" หรือ "ติดตั้งแอป" หลังจากนั้นแอปจะเปิดได้แม้ไม่มีเน็ต
- **ลองบนเครื่องตัวเอง:** รันคำสั่งด้านล่าง แล้วเปิด http://localhost:8000

```bash
cd docs && python3 -m http.server 8000
```

เสียงอ่านใช้เสียงที่ติดตั้งในเครื่อง (Web Speech API) ถ้าเครื่องไม่มีเสียงภาษานั้น ให้ติดตั้งเพิ่มในการตั้งค่าภาษาของระบบ (บน iOS และ Android มีเสียงแบบออฟไลน์ให้ดาวน์โหลด)

## เข้าสู่ระบบและซิงก์ข้ามเครื่อง (ไม่บังคับ)

ถ้าเข้าสู่ระบบด้วยบัญชี Google การ์ด ความคืบหน้า การตั้งค่า และข่าวที่บันทึกไว้จะซิงก์ตรงกันทุกเครื่อง ถ้าไม่เข้าสู่ระบบ แอปก็ทำงานแบบออฟไลน์ได้เหมือนเดิม ระบบนี้ใช้ Firebase ซึ่งต้องตั้งค่าครั้งเดียวดังนี้

1. เข้า https://console.firebase.google.com แล้วกด **Create a project** (ไม่ต้องเปิด Google Analytics)
2. **Build → Authentication → Get started → Sign-in method → Google → Enable** แล้วกด Save
3. **Authentication → Settings → Authorized domains → Add domain** ใส่ `6934468323-hash.github.io`
4. **Build → Firestore Database → Create database** เลือก location ใกล้ๆ (เช่น `asia-southeast1`) และเริ่มที่ **production mode**
5. ที่แท็บ **Rules** ของ Firestore วางกฎด้านล่างแล้วกด Publish (แต่ละคนอ่านและเขียนได้เฉพาะข้อมูลของตัวเอง)
6. **Project settings (ไอคอนฟันเฟือง) → Your apps → `</>` (Web)** ตั้งชื่ออะไรก็ได้ แล้วคัดลอกค่า `firebaseConfig` ไปใส่ใน `src/firebase-config.js` และรัน `python3 build.py` (หรือส่งค่านี้ให้ Claude ทำให้) ค่าเหล่านี้ไม่ใช่รหัสลับ

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

**วิธีซิงก์:** ข้อมูลทั้งหมดของผู้ใช้เก็บเป็นเอกสารเดียว (`users/{uid}`) แต่ละเครื่องรวมข้อมูลกันทีละรายการ การ์ดใบไหนแก้ล่าสุดจะใช้ใบนั้น การ์ดที่ลบในเครื่องหนึ่งจะหายจากทุกเครื่อง คะแนนแบบทดสอบใช้ค่าที่สูงสุด ส่วนการตั้งค่าใช้ชุดที่เปลี่ยนล่าสุด

**ข้อจำกัด:** ถ้าเป็นแอปที่ติดตั้งบน iPhone บางครั้งหน้าต่างล็อกอินของ Google อาจเปิดไม่ขึ้น ให้เข้าสู่ระบบผ่าน Safari ก่อนหนึ่งครั้ง

## เพิ่มเนื้อหา

เนื้อหาอยู่ใน `src/data/` (`fr.js`, `fr2.js`, `fr3.js` และไฟล์ชุดเดียวกันของ `es` และ `nl`) เพิ่มรายการตามรูปแบบเดิมหรือสร้างไฟล์ใหม่แล้วใส่ชื่อในรายการ `DATA` ของ `build.py` แล้วรัน `python3 build.py`

```js
// ประโยค = [ต้นฉบับ, อังกฤษ, ไทย]
// คำศัพท์ = "ระดับ|ชนิดคำ|อังกฤษ|ไทย|รูปพื้นฐาน(ถ้ามี)"   เช่น "B2|v|requires|เรียกร้อง|exiger"
{ id:"fr-f8", cat:"food", lvl:"B1", user:"…", handle:"…", likes:10,
  s:[ ["…","…","…"] ], v:{ "mot":"B2|n|word|คำ" }, c:[ {u:"…", s:[["…","…","…"]]} ] }        // ฟีด
{ id:"fr-r4", cat:"science", lvl:"B2", title:["…","…","…"], p:[[ …ย่อหน้า… ]], v:{…},
  q:[ {t:"main", q:["คำถาม","คำแปลไทย"], o:["A","B","C","D"], a:1, x:"คำอธิบายเฉลย"} ] }   // ความรู้
{ id:"fr-n3", genre:"fantasy", lvl:"B2", title:[…], blurb:"…", p:[[…], "* * *", […]], v:{…} } // นิยาย
```

ลำดับตัวเลือกในแบบทดสอบจะถูกสลับเองตอนแสดงผล และตัวอักษรในคำอธิบายเฉลยจะถูกปรับให้ตรงกับลำดับใหม่โดยอัตโนมัติ

## ไฟล์

- `src/`: ซอร์สโค้ด (`app.js`, `app.css`) และเนื้อหา (`data/`)
- `src/sync.js`, `src/firebase-config.js`: ระบบเข้าสู่ระบบและการซิงก์ (Firebase)
- `build.py`: สร้าง `docs/` (PWA และไฟล์ HTML ไฟล์เดียว) และ `artifact/`
- `docs/`: ไฟล์ที่นำไปใช้งานได้จริง (GitHub Pages ใช้โฟลเดอร์นี้)
