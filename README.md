# Tríada Reader

แอปฝึกอ่านภาษาฝรั่งเศส สเปน และดัตช์ (ภาษาของ UI คือไทย) ใช้งานออฟไลน์ได้ทั้งหมด ยกเว้นฟีเจอร์ที่ระบุว่าเป็นแบบออนไลน์

## ฟีเจอร์

| ส่วน | สิ่งที่ทำได้ |
|---|---|
| **ฟีด** (3.1) | อ่านโพสต์พร้อมคอมเมนต์แบบโซเชียลมีเดีย กรองตามหมวด (อาหาร ท่องเที่ยว ชีวิตประจำวัน เทคโนโลยี กีฬา บันเทิง การงาน ธรรมชาติ) และระดับ CEFR เลื่อนอ่านได้ไม่สิ้นสุด เมื่ออ่านครบจะสุ่มลำดับใหม่แล้ววนอีกรอบ |
| **ความรู้** (3.2) | บทความด้านวิทยาศาสตร์ สุขภาพ สิ่งแวดล้อม สังคม และเศรษฐกิจ กรองตามระดับ CEFR ได้ อ่านจบแล้วมีคำถามปรนัย 5 ข้อแบบข้อสอบ (ใจความสำคัญ ข้อใดไม่สอดคล้อง การอนุมาน ศัพท์ในบริบท จุดประสงค์ และน้ำเสียงของผู้เขียน) พร้อมเฉลยเป็นภาษาไทย มีหน้า "ข่าวล่าสุด" ที่ดึงข่าวจาก Wikinews เมื่อออนไลน์ |
| **นิยาย** (3.3) | เรื่องสั้นแนวสืบสวน โรแมนติก สยองขวัญ ตลก และแฟนตาซี มีแถบบอกความคืบหน้า และจำได้ว่าอ่านถึงไหนแล้ว |
| ทุกโหมด | แตะคำเพื่อดูความหมาย (ไทยและอังกฤษ) รูปพื้นฐานของคำ ชนิดคำ และระดับ CEFR ตรวจจับสำนวนหลายคำได้ แปลทั้งประโยคหรือทุกประโยคเป็นไทยหรืออังกฤษ ฟังเสียงอ่านทั้งเรื่อง (ไฮไลต์ประโยคที่กำลังอ่าน) หรือฟังทีละคำ/ประโยค |
| **การ์ด** | เมื่ออ่านจบ ระบบบันทึกคำยากให้อัตโนมัติ (ค่าเริ่มต้นคือคำที่ยากกว่าระดับของบทความ 1 ขั้น และอย่างน้อย B1) ทบทวนแบบ Spaced Repetition 4 ระดับ (ลืม/ยาก/จำได้/ง่ายมาก) การ์ดแต่ละใบมีประโยคตัวอย่างจากเรื่องที่อ่าน |
| **พจนานุกรม** | ค้นหาคำศัพท์ได้ทั้งจากคำต่างประเทศ (ไม่ต้องพิมพ์เครื่องหมายกำกับเสียง) หรือค้นย้อนกลับจากคำไทย/อังกฤษ แสดงประโยคตัวอย่างจากคลังบทความ เมื่อออนไลน์จะค้นต่อใน Wiktionary และ MyMemory สำหรับคำที่ไม่มีในเครื่อง |
| **ตั้งค่า** | ธีม (ตามระบบ/สว่าง/มืด/กระดาษ) สีหลัก ขนาดตัวอักษร ระยะบรรทัด ฟอนต์ ภาษาคำแปล ขีดเส้นใต้คำยาก เกณฑ์คำยาก ด้านหน้าการ์ด จำนวนการ์ดต่อรอบ ความเร็วและเสียงอ่าน ส่งออก/นำเข้าข้อมูล |

## วิธีใช้งาน

- **ไฟล์เดียว:** เปิดไฟล์ `dist/triada-offline.html` ในเบราว์เซอร์ได้เลย ไม่ต้องใช้อินเทอร์เน็ต
- **ติดตั้งเป็นแอป (PWA):** นำโฟลเดอร์ `dist/` ไปวางบนโฮสต์ HTTPS ใดก็ได้ เช่น GitHub Pages หรือ Netlify เปิดเว็บหนึ่งครั้ง แล้วกด "เพิ่มลงหน้าจอหลัก" หรือ "ติดตั้งแอป" หลังจากนั้นแอปจะเปิดได้แม้ไม่มีเน็ต
- **ลองบนเครื่องตัวเอง:** รันคำสั่งด้านล่าง แล้วเปิด http://localhost:8000

```bash
cd dist && python3 -m http.server 8000
```

เสียงอ่านใช้เสียงที่ติดตั้งในเครื่อง (Web Speech API) ถ้าเครื่องไม่มีเสียงภาษานั้น ให้ติดตั้งเพิ่มในการตั้งค่าภาษาของระบบ (บน iOS และ Android มีเสียงแบบออฟไลน์ให้ดาวน์โหลด)

## เพิ่มเนื้อหา

เนื้อหาอยู่ใน `src/data/{fr,es,nl}.js` เพิ่มรายการตามรูปแบบเดิม แล้วรัน `python3 build.py`

```js
// ประโยค = [ต้นฉบับ, อังกฤษ, ไทย]
// คำศัพท์ = "ระดับ|ชนิดคำ|อังกฤษ|ไทย|รูปพื้นฐาน(ถ้ามี)"   เช่น "B2|v|requires|เรียกร้อง|exiger"
{ id:"fr-f8", cat:"food", lvl:"B1", user:"…", handle:"…", likes:10,
  s:[ ["…","…","…"] ], v:{ "mot":"B2|n|word|คำ" }, c:[ {u:"…", s:[["…","…","…"]]} ] }        // ฟีด
{ id:"fr-r4", cat:"science", lvl:"B2", title:["…","…","…"], p:[[ …ย่อหน้า… ]], v:{…},
  q:[ {t:"main", q:["คำถาม","คำแปลไทย"], o:["A","B","C","D"], a:1, x:"คำอธิบายเฉลย"} ] }   // ความรู้
{ id:"fr-n3", genre:"fantasy", lvl:"B2", title:[…], blurb:"…", p:[[…], "* * *", […]], v:{…} } // นิยาย
```

ลำดับตัวเลือกในแบบทดสอบจะถูกสลับเองตอนแสดงผล และตัวอักษรในคำอธิบายเฉลยจะถูกปรับให้ตรงกับลำดับใหม่โดยอัตโนมัติ

## ไฟล์

- `src/`: ซอร์สโค้ด (`app.js`, `app.css`) และเนื้อหา (`data/`)
- `build.py`: สร้าง `dist/` (PWA และไฟล์ HTML ไฟล์เดียว) และ `artifact/`
- `dist/`: ไฟล์ที่นำไปใช้งานได้จริง
